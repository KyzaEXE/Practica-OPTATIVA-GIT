# Practica OPTATIVA GIT y GitHub

Repositorio de la practica de Git y GitHub: comandos locales, publicacion en un remoto y clonacion.

## Contenido del proyecto

- `index.html` - estructura basica de la pagina.
- `app.js` - script de ejemplo.
- `style.css` - hoja de estilos.
- `.gitignore` - excluye `Test/`, `Test2/` y `Prueba3`.
- Rama `login` - carpetas `login/` y `autenticacion/` con su codigo.

## Comandos practicados

`git init`, `git status`, `git add`, `git commit`, `git log`, `git checkout`, `git diff`, `git branch`, `git remote`, `git push`, `git clone`.
